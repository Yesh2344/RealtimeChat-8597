# RealtimeChat![Go](https://img.shields.io/badge/Go-1.22-blue)![License](https://img.shields.io/badge/License-MIT-green)

RealtimeChat is a production‑ready real‑time chat server built with Go and WebSockets. It demonstrates modern Go architecture, clean error handling, structured logging, configuration management, and comprehensive testing.

## Features

- **WebSocket** based real‑time messaging
- Broadcast to all connected clients
- Graceful shutdown & context handling
- Structured logging with Logrus
- Configuration via environment variables (`.env`) or `config.yaml`
- CORS middleware for browser clients
- Unit tests for core hub logic
